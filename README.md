# Marimba!

A tiny sandbox game where you can spawn creatures and plants, help them grow,
and try not to overwater anything.

Created by Vivien Cai and Tasha Lin with [p5.js](https://p5js.org/).

## Run locally

The game is a static site. From the repository root, start a local server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Controls

- Use the top buttons to spawn a creature or plant.
- Select food to feed and grow creatures.
- Select water to grow plants. Too much water will kill them.
- The sword can be used on adult creatures.
- Use the pause button in the upper-left corner to pause or resume the game.
